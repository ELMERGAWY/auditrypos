# Smart Restaurant Hub

قم بتنفيذ البرومبت واذا احتجت شيئا فتحدث باللغة العربية You are an expert Full-Stack Developer. Build a complete, production-ready SaaS platform for Restaurant Management called "SmartResto POS".

1. Core Architecture & Access Control:

Create 3 distinct views: Landing Page, Restaurant Dashboard (POS), and Super Admin Portal.

Super Admin Access: Use a hardcoded admin route /super-admin-portal. This portal must allow me to:

View all registered restaurants.

Control Status: Activate, Suspend, or Delete any restaurant account.

License Key System: A tool to generate unique 16-digit encrypted keys (e.g., SR-XXXX-XXXX). When generated, I specify the duration (30 days, 180 days, 365 days).

Manual Payment Review: A table to see users' uploaded payment receipts and approve them.

System Backup: A button to export the entire Database (JSON) for safety.

2. Restaurant Dashboard & POS Features:

Offline-First Engine: Implement a robust logic using LocalStorage or IndexedDB. If navigator.onLine is false, save all orders and menu changes locally. Automatically sync with the server once the connection is restored.

POS Interface: A grid-based menu (images + prices), a cart system, and "Checkout" with receipt generation.

QR Menu Generator: A section where the owner can customize their menu and download a unique QR code.

Waiter Call System: A real-time notification panel that flashes and plays a sound whenever a customer from the QR Menu clicks "Call Waiter".

3. QR Menu (Customer View):

A beautiful, mobile-optimized menu accessible via a unique ID.

Features: Browse categories, search items, and a floating "Call Waiter" button.

4. Subscription & Global Payment System:

Lock System: If a restaurant's subscription expires, lock the dashboard with an overlay showing "Account Suspended".

Payment Gateway UI: A professional payment page displaying:

InstaPay: 01096016070

Vodafone Cash: 01044377070

PayPal: abdelsabourmergawy@gmail.com

Bank Transfer: [Placeholder for details]

Activation: The user must either enter a valid "License Key" (generated by me) or upload a screenshot of their transfer for my approval.

5. Design & Tech Stack:

UI: Modern, high-end Dark Mode for dashboards. Use Tailwind CSS and Lucide-react icons.

Responsiveness: Must be perfect on iPads (for POS) and Mobile (for QR Menu).

Interactions: Use Framer Motion for smooth transitions between "Offline" and "Online" states.

6. Implementation Note:

Build all logical connections between the Super Admin and the Restaurant User.

Ensure that the "License Key" once used, cannot be used again and is linked to that specific restaurant ID.
